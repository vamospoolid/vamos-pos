VAMOS POOL & CAFE - PANDUAN INSTALASI KASIR (V2.5 - FULLY AUTOMATED)
===========================================================

APA YANG BARU DI V2.5:
1. Automated Database Installer: Script otomatis mengunduh & memasang PostgreSQL.
2. Auto-Migration & Seed: Database "vamos_pos" dibuat & diisi data awal otomatis.
3. Smart Hardware Detection: Aplikasi otomatis mencari port Relay (CH340).
4. Auto-Fallback: Jika port manual salah, aplikasi akan mencari port yang benar.

LANGKAH 1: INSTALASI UTAMA (1-KLIK)
1. Ekstrak seluruh file folder installer Vamos POS.
2. Klik kanan file "MASTER_SETUP.bat" -> Klik "Run as Administrator".
3. Script otomatis akan:
   - Mendeteksi/mengunduh/menginstal PostgreSQL 16 secara latar belakang (silent).
   - Mengatur password default: "admin" (port 5432).
   - Membuat database "vamos_pos" secara otomatis.
   - Melakukan migrasi struktur tabel database & data inisial (seeding).
   - Membuka port Windows Firewall 3000 untuk backend.
   - Membuat shortcut "VAMOS POS" di Desktop Anda.

LANGKAH 2: KONFIGURASI HARDWARE (PENTING)
1. Sambungkan alat Relay USB (CH340) ke laptop.
2. Secara default file ".env" lokal dikonfigurasi: RELAY_COM_PORT=COM3.
3. Jika ingin sistem mendeteksi otomatis port USB, Anda bisa mengubah nilai di file ".env":
   RELAY_COM_PORT=AUTO
4. Driver CH340 harus sudah terinstall agar hardware terbaca.

LANGKAH 3: SETTING PRINTER STRUK
1. Hubungkan printer thermal kasir Anda ke USB.
2. Share printer tersebut di Windows dengan nama: RP58 (atau sesuaikan di Settings aplikasi).
3. Pastikan "File and Printer Sharing" aktif di Windows Network Settings.

LANGKAH 4: JALANKAN APLIKASI
1. Buka shortcut "VAMOS POS" di Desktop Anda.
2. Cek pojok kanan atas: Indikator Hardware status port COM3/AUTO harus berwarna HIJAU.
3. Jika indikator MERAH, jalankan file "DIAGNOSE_HARDWARE.bat" untuk diagnosa hardware.
